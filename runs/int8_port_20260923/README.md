## 무라벨에서의 차이 (`fulldiff.py`, 기준 대비)

| 변형 | 무라벨 750 4bit | 무라벨 750 int8 |
|---|---|---|
| `port_a`(첫 판) | +v1 2(손라벨 0 1, 미라벨 1) · −v11 1(0) · −v13 2(0 1, **1 1**) | +v1 1(보험사 본사, 미라벨) · −v11(0) · −v13 2(0, **1**) · −v16(0) |
| **채택본** | −v11 1(0) | −v11(0) · −v16(0) |

첫 판의 문제 변경은 전부 **본 호출 근거(v1 근거 필수·기업규모 재분류)에 공백 복원을 건 것**에서 나왔다. 이 필드의 공백 불일치는 4bit도 같은 비율(14.1% vs 13.0%)이라 int8 고유 문제가 아니므로, 채택본은 공백 복원을 전용 호출의 줄 단위 검사(`_verified_lines`)와 e열 근거에만 쓰고 본 호출 근거에는 문서명 접두어 제거만 쓴다. dev 이득 3건(DEV-058 v1은 문서명 제거, DEV-051 v14는 전용 호출 복원, DEV-079 v24는 업종코드)은 그대로다.

무라벨 20,000 정규식 재생: 채택본 v24 +18, 예외 0(첫 판과 같은 18공고).
