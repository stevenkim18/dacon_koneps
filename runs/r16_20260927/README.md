## 요점

- 지금까지 주입 탐침(Q·H·H2·H3·H4)은 **Claude가 dev 편집 문체를 본떠 쓴 문장**이었다. 이번에는 무라벨 공고의 **실제 자격 줄**을 모아 규칙이 못 읽는 줄을 필터별로 나눴다.
- **실적:** `EVAL_CONTEXT_RE`의 '인정·대상으로·합산·건수·실적만'(평가 기준 줄을 거르려던 낱말)이 참가자격 문장도 지웠다 — 고유 문장 기준 '인정' 36 · '대상으로' 28 · '합산' 8 · '실적만' 6. 예: '공공기관을 대상으로 단일건 1천만원 이상 … 실적이 1건 이상 있는 업체', '…실적이 있는 업체(실적증명원 원본 제출 시에만 인정)'. 09-23 ⑤가 '아직 재지 않았다'고 적어 둔 위험이다.
- **지역:** 지명 약칭(서울·경기·전남, 92) · '평가' 필터(수련시설 '종합평가 적정', 23) · '소재 업체' 불인정(22) · 첫 40자 '위치·납품·주소' 필터(45) · '확인서' 필터(기업규모와 지역 자격이 한 줄, 19).
- **자연 줄 탐침 N(v2):** wrap_r15 404/480(84%) → R16 448/480(93%). 남은 누락은 권고사항·<삭제>·'…에 한하여 인정'(평가 기준) 등 거르는 게 맞는 줄이 대부분. 지역은 자연 자격 줄 대부분이 전체 이름이라 v7 472 → 480/480, v6 480/480(차이 작음).
- **판독으로 걸러 낸 오탐 문맥(첫 판 → 최종):** '…소재 업체를 우대', 평가표 ': 5점', 입찰보증금 면제 조건, '…실적이 있는 업체 중, 수행 건수의 실적', <삭제> 조항, 자재 '관내업체에서 구입', '왕복 40㎞ 이내에 소재한 업체'. 되살린 지역 줄은 자격 절 구간만 쓰게 해 줄의 다른 곳의 기초 토큰이 v6를 뒤집지 않게 했다(첫 판 v6 +5 → +2).
- **v4 '국가' 오독:** '국가종합전자조달시스템에 … 등록한 업체로 … 실적', '국가에서 인증받은 … 시설 … 실적'이 v4(공공 발주처 한정)로 켜졌다. 무라벨 20,000 v4 −8(6공고 판독, 전부 발주처 한정 아님).
- 탐침 N2: v21 216/240(두 판 같음). v22 '누락'은 대부분 **제안**설명회(PT) 불참 시 평가 제외라 v22가 아니고, v12 '누락'은 넣은 줄이 다른 경쟁제품 코드를 품어 공고가 경쟁제품이 된 탐침 한계다(dev 편집 DEV-15는 그 공고 품목 코드를 쓴다). v19 '입찰 전, … 확약서 1부 제출 필수'는 규칙이 못 읽지만 서류 목록형이라 dev 라벨이 갈려(DEV-033 = 1, DEV-051·057 = 0) 손대지 않았다.
- 버린 것·안 한 것: 기업규모 제외어('평가·신용·경쟁제품')는 서버 전용 호출이 '없음' 칸을 채우는 구조라 이번에 건드리지 않음. v24 지역 축(meta N인데 본문 지역 제한)은 dev 편집 지역 불일치 11건 중 v24 라벨 2건이라 계속 보류.
