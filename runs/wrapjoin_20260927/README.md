## 요점

- **문장 가운데 줄바꿈(T2)이 규칙 경로의 가장 큰 구조적 구멍이었다.** 한 줄씩 보는 `_lines()`가 '…실적이 ⏎ 있는 업체'의 자격 어미를 놓친다. 기준판 T2: v4 15/110 · v1 15/120 · v5 25/110 · v6 10/40 · v7 10/50 · v21 35/100 · v19 10/25. 기업규모 계열은 09-24 여러 줄 파서 덕에 멀쩡했다.
- 빈 줄을 건너 이으면(기업규모 파서의 `_continues`) 표 칸끼리 붙어 쓰레기 문장이 생긴다. W는 **빈 줄 없이 바로 이어지는 줄만** 잇는다.
- 지역 이은 문장은 조심해야 한다. 이은 줄에 섞인 공고 머리글·현장 주소·협정서 서식의 기초 토큰이 공고 전체 지역 단위를 시군구로 뒤집었다(첫 판 20,000 v6 +18, 거의 전부 오탐). 그래서 '영업소·소재지 → 지명 → 소재·둔' 구간만 쓴다(v6 +0).
- 새 보류 세트 H3(dev 편집 문체)에서 기준판의 한 줄 재현율이 낮았다: **v2 18/60 · v12 6/36 · v1 6/60**. R15 뒤 H4(설계에 안 씀)에서 v2 0 → 18/30 · v3 12 → 18/18 · v19 12 → 18/18로 일반화했다. v12는 처음 판이 H4에서 0/24라 구조 패턴으로 넓혔다. v1은 새 표현을 정규식으로 거의 못 잡는다(서버 본 호출 LLM 몫).
- 버린 것:
  - R15 첫 판의 'N건 이상'으로 끝나는 줄·'실적 기준:' 머리말 규칙: 평가표 줄이 켜졌다(20,000 v2 +56).
  - 동사 '완료한': '완료한 실적에 한함' 각주가 통과했다.
  - v1 인용 공백 복원: dev 0 · 750 +1, 보험업법 허가 요건.
  - v24 본문 계약방법 축: dev 5월 묶음 2건만 켜짐.
  - v2 '대행 경력 … 보유한 사업자': 기존 인력 필터 수정이 필요해 보류.
- 제거형 편집 흉내(`runs/edit_model_20260923/removal_test.py`): 자연 공고에서 기업규모·직생·대기업 줄을 지우면 부재 항목이 v18 5/40 · v11 5/40 · v10 4/40 · v16 18/40 · v20 28/40만 켜진다. 남은 확인서 주석·줄바꿈 뒷줄 때문이다. 다만 dev 부재형 정답에 남은 줄은 서류 목록뿐이고 dev 재현율은 높다(v18 7/7). 편집이 깔끔하게 지운 것으로 보고 손대지 않았다.
