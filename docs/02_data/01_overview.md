## 설명

본 대회의 데이터는 입찰공고 1건이 한 레코드(JSONL 한 줄)이며, 각 레코드는 공고문·첨부 문서의 정규화 텍스트와 나라장터 등록 정보(meta)로 구성됩니다.

본 대회는 라벨이 부착된 학습 데이터셋을 제공하지 않습니다.

라벨링되지 않은 실제 공고 데이터에서 출발하여 학습·검증에 필요한 라벨을 참가자가 직접 설계·생성하는 것(자가 라벨링)까지가 과제의 일부이며, 자가 라벨링은 전면 허용됩니다.

자가 라벨링 안내와 상세 데이터 명세는 토크 게시판의 데이터 명세 글을 참고해 주세요.

## 제공 데이터

### train_unlabeled.jsonl.gz

- 무라벨 입찰공고 20,000건
- 라벨이 제공되지 않음
- 실제 위반 공고가 섞여 있을 수 있음
- 정상 데이터라는 보장은 없음
- 자가 라벨링을 통한 학습·검증셋 구성에 활용 가능
- 검색(RAG) 사례집 구성에 활용 가능
- 후처리 규칙 튜닝에 활용 가능

### dev.jsonl.gz / dev_labels.csv

라벨 예시 공고 200건과 정답 라벨을 제공합니다.

- 제출 형식과 동일한 49열
- 24개 검토 항목 전부에 대해 위반 예시 포함
- 항목당 위반 예시 5~8건
- 정상 예시 112건
- 근거 문구 예시 포함

dev는 항목별 판정 유형을 보여주기 위한 예시 세트입니다. 실제 평가 데이터의 구성비는 dev와 다르며 공개하지 않습니다.

### sample_submission.csv

49열로 구성됩니다.

- id
- v1~v24: 위반 여부
- e1~e24: 근거 문구

#### 위반 여부

- 정수 0/1로 기재
- 판단이 어려운 항목도 비워두지 말고 0으로 제출
- true, "1" 등은 형식 위반

#### 근거 문구

- 위반으로 판정한 항목의 근거 문구
- 제공된 본문의 부분문자열 그대로 사용
- 요약·수정 시 무효
- 500자 이하
- 위반이 아니면 빈칸
- 10·11·16·18·20번 항목은 부재탐지형이므로 항상 빈칸

#### 형식

- UTF-8, BOM 없음
- NFC 정규화
- RFC4180 quoting
- 수식 접두 문자 =, +, @ 금지
- 행 수는 입력 건수와 동일

## 레코드 형식

train_unlabeled, dev, test는 공통적으로 JSONL 한 줄에 입찰공고 1건을 담습니다.

| 키 | 내용 |
|---|---|
| id | 공고 식별자. 제출 파일의 id 열에 그대로 사용 |
| docs | 문서 배열 |
| meta | 나라장터 등록 정보 21필드 |
| dropped_doc_counts | 길이 예산 초과로 제외된 문서 종류·개수 |
| input_completeness | 관측 완전성 bool 4종 |
| anon_applied | 익명화 적용 여부. 전건 true |
| assembly_policy_version | 데이터 조립 규약 버전 |

docs의 각 원소는 다음 필드를 가집니다.

- doc_id
- type
- text

type은 다음 5종입니다.

- 공고문
- 규격서
- 과업지시서
- 제안요청서
- 예외공표서

text는 NFC 정규화 텍스트이며 표는 |로 복원되어 있습니다.

공고문은 항상 1건 이상 포함됩니다.

위반이 첨부 문서에만 나타나는 항목이 있으므로 공고문만으로 판정을 끝내지 않는 것을 권장합니다.

dropped_doc_counts가 비어 있지 않은 공고는 일부 첨부가 제외된 상태입니다.

첨부에 없으니 위반이라고 단정하면 부재탐지형 항목 판정이 틀릴 수 있습니다.

- 입찰추정가격
- 소관구분
- 공동도급구성방식
- 정보화사업여부
- 세부품명번호목록
- 제한지역코드목록
- 지역제한여부
- 면허업종제한목록
- 업종제한여부
- 조항호내용
- 공고게시일자
- 개찰예정일자
- 긴급공고여부
- 입찰방법
- 조달방식

값이 없으면 null, 등록 자체가 안 됐으면 미입력입니다.

둘 다 해당 없음이 아니며, 비어 있다는 사실 자체가 판정 재료인 항목이 있습니다.

meta는 원칙적으로 본문과 정합하지만 24번 항목인 정보 불일치만 예외입니다.

본문 기재값과 meta 값이 서로 다른 경우:

- 적용 법령·금액 구간 판단: 공고문 기재값 우선
- 본문에 기재가 없는 값: meta 기준
- 불일치 자체: v24 판정 대상

### 익명화

기관명·담당자·연락처·주소·공고번호는 토큰으로 치환되어 있습니다.

예시:

    [수요기관(기초자치단체)|지역=r1]

괄호 안 기관 유형은 판정에 사용할 수 있습니다.

    [지역:r1|단위=기초|광역=경기도]

지역제한 판정에 사용할 수 있습니다.

- 한 문서 안에서 r1, r2는 서로 다른 지역
- 광역 시도명은 원문 그대로 유지
- 단위=기초는 시·군·구 단위를 의미

다음 항목은 치환되지 않았습니다.

- 금액
- 수량
- 날짜
- 법령 조문
- 품명
- 규격

익명화된 식별자를 공개 원문과 대조하여 복원하는 행위는 금지됩니다.

제공되는 모든 텍스트는 NFC 정규화된 UTF-8입니다.
