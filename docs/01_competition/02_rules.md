# 대회 안내 - 규칙

> 출처: https://dacon.io/competitions/official/236754/overview/rules

## 1. 개인 또는 팀 참여 규칙

개인 또는 팀을 이루어 참여할 수 있습니다.

- 개인 참가: 팀 신청 없이 제출 탭에서 제출 가능
- 팀 참가: 팀 탭에서 가능
- 팀 구성: 팀 페이지에서 팀 구성 안내 확인
- 팀 최대 인원: 5명
- 동일인이 개인 또는 복수팀에 중복하여 등록 불가

## 2. 대회 규칙

### 2-1. 고정 LLM 기반 파이프라인 개발 대회

본 대회는 지정된 고정 LLM을 기반으로 추론 파이프라인(전처리·프롬프트 구성·검색·후처리 등)을 개발하는 대회입니다.

- 고정 LLM: google/gemma-4-26B-A4B-it
  - 리비전: 4d7ae4984b7db7de8f8457170b3f1a419ee76d52
- 보조 임베딩 모델: BAAI/bge-m3
  - 리비전: 5617a9f61b028005a4858fdac845db406aefb181

두 모델은 평가 서버에 미리 준비되어 있으므로 참가자가 모델을 제출할 필요가 없으며, 제출해서도 안 됩니다.

제출물은 추론 코드와 RAG 인덱스 등 정적 자산으로만 구성합니다.

고정 LLM에 대한 파인튜닝(LoRA·QLoRA 등 어댑터 학습 포함) 및 모델 가중치·어댑터의 제출·로드는 허용되지 않습니다.

고정 LLM과 보조 임베딩 모델 외에 참가자가 학습시킨 모델 가중치를 위반 여부 판정에 사용하는 것도 허용되지 않습니다. 분류기·회귀 모델·추가 임베딩 모델 등 종류를 불문합니다.

model/에는 RAG 검색 인덱스 등 정적 자산만 포함할 수 있습니다.

제출된 추론 코드는 평가 데이터의 각 공고에 대해 고정 LLM 정상 호출을 1회 이상 수행해야 합니다.

정상 호출이란 해당 공고의 내용을 포함한 프롬프트로 고정 LLM을 호출하여 정상 응답을 받는 것을 말합니다.

모델 호출이 없거나 공고 내용과 무관한 호출만 있는 제출물은 제출 요건 미충족으로 무효 처리될 수 있습니다.

모델 출력에 대한 후처리·규칙 기반 보정은 자유롭게 허용됩니다.

로컬 개발 환경(GPU·런타임·정밀도)은 자유입니다.

### 2-2. 외부 데이터 사용 금지 및 자가 라벨링 허용

학습·검증·추론 파이프라인과 제출물에는 대회에서 제공하는 데이터와 자료만 활용할 수 있습니다.

#### 허용되는 것

- 무라벨 20,000건
- dev 200건
- data/ 폴더의 항목표·법령패키지
- 자가 라벨링
  - 수작업
  - 규칙 기반
  - 모델 기반
- 라벨 생성 단계에 한해 외부 LLM(상용 API 포함) 사용
  - 외부 LLM에는 대회 제공 자료만 입력 가능
- 공개 오픈소스 라이브러리
- 모델 출력 후처리·규칙 기반 보정
- 본 대회 코드 공유 게시판에 전체 공개된 참가자 생성 자료

#### 금지되는 것

- 나라장터·공공데이터 API·웹 크롤링
- 외부 입찰공고·메타데이터·라벨·정답성 정보 사용
- 공개 원문과 대조하여 익명화된 식별자 복원
- 외부 LLM의 웹 검색·외부 문서 결합
- 제출 추론 코드의 외부 LLM·외부 API 호출
- 제공 자료 외 데이터·법령·라벨을 pip 패키지나 model/ 폴더로 반입
- 참가자 생성 라벨·가공 데이터의 특정 팀 간 사적 공유

공유는 본 대회 코드 공유 게시판을 통한 전체 공개만 허용됩니다.

판정 기준은 배포된 법령 패키지의 스냅샷으로 고정됩니다.

- 법령·행정규칙 전문
- 중소벤처기업부 고시 제2025-96호(2025.08.29)

채점도 이 스냅샷을 기준으로 하며 대회 기간 중 법령 개정은 반영되지 않습니다.

개인적인 법령 공부는 제한하지 않지만, 파이프라인·제출물에 결합하는 법령 자료는 배포된 법령 패키지를 사용해야 합니다.

### 2-3. 재현 가능성 및 출처 명시 의무

수상팀의 결과물은 대회에서 제공한 자료와 제출 자료만으로 재현이 가능해야 합니다.

재현이 불가능한 경우 수상이 취소될 수 있습니다.

자가 라벨링을 사용한 경우 다음도 재현 대상에 포함됩니다.

- 라벨 생성 코드
- 프롬프트
- 절차

외부 LLM으로 생성한 라벨은 생성 코드·프롬프트·사용 모델 버전 기록과 생성된 라벨 데이터를 제출하여 재현을 갈음할 수 있습니다.

2차 평가 자료 제출 시 결과물 산출에 사용된 모든 요소의 출처를 명확하게 기술할 수 있어야 합니다.

### 2-4. 비공개 평가 데이터를 활용한 추가 학습 금지

제출 추론 코드에서는 예측을 위한 전처리·후처리 및 추론 과정을 자유롭게 구성할 수 있습니다.

다만 비공개 평가 데이터셋을 활용한 다음 행위는 허용되지 않습니다.

- 추가 학습
- 모델 튜닝
- Pseudo-Labeling
- 모델 또는 규칙 갱신

### 2-5. 비공개 평가 데이터의 공고 단위 독립 예측 원칙

비공개 평가 데이터의 각 공고 샘플은 서로 독립적으로 예측해야 합니다.

#### 허용

하나의 공고 샘플 내 문서(공고문·첨부)를 분할하여 추론하고 결과를 종합하는 방식

#### 금지

다른 공고 샘플의 정보·예측값·통계를 활용하여 예측값을 생성하거나 보정하는 방식

## 3. 2차 평가 자료 제출 규칙

대회 종료 후 2차 평가 대상자는 안내되는 양식에 맞추어 dacon@dacon.io로 기한 내 자료를 제출해야 합니다.

제출 파일 목록 및 세부 양식은 2차 평가 진출팀에 별도 안내됩니다.

제출 대상에는 다음이 포함됩니다.

- 리더보드 점수 재현이 가능한 코드 및 실행 방법
- 자가 라벨링에 사용한 라벨 생성 코드·프롬프트
- 결과물 산출에 사용된 모델·도구·자료의 출처 명세
- 팀 구성원의 성명·생년월일·성별·현재 소속

## 4. 유의 사항

- 1일 최대 제출 횟수: 1회
- 사용 가능 언어: Python
- 모든 CSV 형식 데이터와 제출 파일은 UTF-8 인코딩
- 대회 종료 시점의 Private 리더보드는 최종 순위가 아님
- 2차 평가와 검증 이후 최종 수상자 결정
- 평가 데이터셋 유출 시도 등 부정 행위 발견 시 즉시 실격
- 데이콘 부정 제출 정책 적용

데이콘 답변을 희망하는 경우 토크 게시글 댓글로 질문을 올립니다.
