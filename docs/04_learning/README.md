## 먼저 기억할 것

첫 목표는 **공고 한 건을 이해하고, 공식 베이스라인으로 입력부터 결과 저장까지 연결하는 것**이다. 베이스라인은 출발점으로 제공된 예제 코드다.

이후에는 `실제 모델 실행 → 기준 점수 측정 → 오답 분석 → 한 가지 개선 → 재평가`를 반복한다. 책은 막힌 개념을 찾는 참고서로 사용한다.

## 전체 학습 지도

| 분야 | 지금 필요한 범위 | 이후 넓힐 범위 |
|---|---|---|
| Python·데이터 | JSONL·CSV 읽기, 문자열, pandas 집계 | NumPy, 데이터 정제, 표본·분포 분석 |
| 머신러닝·평가 | 라벨, 검증셋, precision/recall/F1, 데이터 누수 | 학습·최적화·일반화·통계적 불확실성 |
| 신경망·LLM | 토큰, 컨텍스트, 프롬프트, 추론, 구조화 출력 | 벡터·행렬, 역전파, Transformer, 학습 방식 |
| 검색·RAG | 관련 조문 제공, 기본 검색, 원문 근거 확인 | 임베딩, 하이브리드 검색, 재정렬, 검색 평가 |
| 입찰·법령 | 24개 항목의 적용 조건·예외·사례 | 계약법 체계와 도메인 판단 능력 |
| 시스템 | 결과 검증, 로그, 실행 시간, 재현 가능한 설정 | 추론 최적화, 운영·관측, 보안 |
