**전용 호출은 반복 실험이 가능한 비용이다.** 본 호출만 하룻밤짜리다.

## 2. 채택: 용역 공고의 물품 코드는 원문 근거가 있을 때만 (P)

품목 과탐 3건을 원문에서 보니 둘은 프롬프트가 아니라 로직 문제였다.

전용 호출은 스키마가 **용역 코드(앞 2자리 ≥ 70) 29개 + 해당없음**으로 제한돼 있지만 본 호출은 제한이 없다. 용역 공고 592건 중 **10건**에서 본 호출이 물품 코드를 골랐다.

## 4. 기각: 품목 전용 호출 프롬프트 교체

남은 과탐 `PPS-DEV-03`은 **건축 설계 용역인데 '디자인서비스'(분류: 편집디자인그래픽및예술관련서비스)**를 골랐다. 이건 로직으로 못 고치고 프롬프트다. 두 가지를 고쳤다.

1. 카탈로그에 **분류(category)**를 추가: `- 8214150201 디자인서비스 [아트디자인서비스 / 편집디자인그래픽및예술관련서비스]`
2. 목록에 없어 "해당없음"인 대표 용역을 명시: 건축·토목·조경 설계와 감리, 학술·연구·조사·평가, 교육·강의 운영, 시설 위탁운영, 홍보대행, 인쇄물 제작 등

dev 122건을 9분에 재생성했다. **62건 중 17건에서 코드가 바뀔 만큼 반응은 컸다.**

- `DEV-03` 디자인서비스 → **해당없음** (의도한 수정)
- `DEV-064` 해당없음 → 정보시스템유지관리서비스 (v10·v11 누락 건)
- 수학여행·교육 운영·지질조사 여러 건 → 해당없음

그런데 판정이 실제로 달라진 dev 공고는 **2건뿐**이고 합은 마이너스였다.

| 공고 | 변화 | 판정 |
|---|---|---|
| PPS-DEV-03 | v10 1→0 ✓, v13 1→0 ✓, **v18 0→1 ✗** | 경쟁제품에서 빠지자 v14~v18 블록이 열려 v18 오탐이 새로 생겼다 |
| PPS-DEV-056 | **v12 1→0 ✗, v13 0→1 ✗** | 공고가 요구한 직생확인 품명(8111219901 인터넷지원개발서비스)을 그대로 따라갔다. 라벨은 비경쟁제품(v12=1) |

교차검증 0.8340 → **0.8308**.

DEV-056만 겨냥해 "공고가 어떤 세부품명의 직접생산확인증명서를 요구하더라도 그 번호를 그대로 고르지 않는다"로 경고를 강화한 2차 시도는 **더 나빴다**(교차검증 **0.8266**, v12 0.833 → 0.769).

**두 변형 모두 기각.** 메모에 "v10은 프롬프트 수정 + 재추론이 유일한 길"로 적어 둔 가설은 이것으로 측정에 의해 닫힌다 — 적어도 로컬 MLX 4bit 기준으로는, 품목 프롬프트를 건드리면 디자인 계열 과탐이 줄어드는 만큼 8111(정보시스템) 계열 과탐이 늘어 합이 마이너스다.

남은 품목 오답은 `DEV-03`(v10·v13 오탐), `DEV-191`(v12 오탐), 재현 불가 라벨 2건이다.
