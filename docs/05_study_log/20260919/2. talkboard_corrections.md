## 바로 적용할 우선순위

1. v9의 `"동등"이면 항상 0` 규칙을 제거하거나 문맥 판정으로 바꾼 후보를 저장된 출력으로 재채점한다.
2. 모든 수의계약을 v14~v18에서 제외하는 게이트를 분리 실험한다. 공개 dev의 재현 불가능 사례는 예외 규칙으로 맞추지 않는다.
3. v20의 사업금액 계산을 추정가격+부가세로 바꾼 경우와 현재 값을 비교한다. 장기계속·분할발주는 문서에서 산식에 필요한 값을 얻을 수 있을 때만 적용한다.
4. logprob 임계값은 모델 호출 형식, 속도, 재현성을 먼저 검증한 뒤 항목별 교차 검증으로 조정한다.
