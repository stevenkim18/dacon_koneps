# 2026-09-25 ② 09-26·09-27 후보 재검토 — 서버 경로에서 v1 정규식 보조가 꺼져 있었다

> 앞 문서: [① v8nat 0.7053 결과와 적용 범위 대조](1.%20v8nat_result_and_scope_audit.md). 결과물: [`submissions/20260926_phrase_parser_recall_v1fix`](../../../submissions/20260926_phrase_parser_recall_v1fix/README.md) · [`submissions/20260927_private_scope_recall_v1fix`](../../../submissions/20260927_private_scope_recall_v1fix/README.md). 도구: [`runs/review_20260925/`](../../../runs/review_20260925/README.md).
> 모든 수치는 CPU 계산과 저장 출력(dev 4bit·int8 2벌, 무라벨 750 4bit·int8)·무라벨 20,000 정규식 재생으로 쟀다. GPU 실행·제출은 없다.

## 요약

- **09-26 후보의 7번 변경(v1 정규식 보조)은 서버에서 작동하지 않는다.** `ITEM_SOURCE["v1"]="or"`가 `특정기관_한정`만 합치고 근거는 LLM 값(대개 null)을 써서 근거 공란 규칙에 걸린다. 주입 시험이 LLM 출력 없는 경로만 쟀기 때문에 보이지 않았다. int8 저장 출력을 둔 채 주입하면 0/60, `FACT_KEYS`에 `특정기관_근거`를 넣으면 60/60. 저장 출력 5벌·20,000 재생 모두 판정 변화 0이다. 09-27 후보도 같은 문제라 둘 다 `_v1fix` 폴더로 고쳤다.
- 같은 종류의 문제(정규식 사실이 출처 정책 때문에 서버에서 무시됨)를 전 항목에서 찾았다. **다른 항목에는 없었다.** 정규식 출처 항목은 LLM 출력 유무와 무관하게 같은 재현율이다.
- 새 레버 다섯 가지를 쟀다. 채택할 만한 큰 것은 없고, 작은 안전망 두 개(v13·v15 수준 보충, v19 정규식 OR)만 남는다.

## 1. 버그

| | 내용 |
|---|---|
| 코드 | `merge_facts(llm, rx, policy)`는 `policy`에 든 키만 모드대로 합치고 나머지는 LLM 값을 쓴다. `or` 모드 정책은 `{k: "or" for k in FACT_KEYS}` |
| 문제 | `특정기관_한정`은 `BOOL_KEYS`라 `FACT_KEYS`에 들어 있지만 `특정기관_근거`는 없다 → 근거 = LLM 값 |
| 판정 | `v1 = 특정기관_한정 ∧ clean_evidence(특정기관_근거)` → LLM이 그 줄을 놓치면 근거가 null이라 v1=0 |
| 왜 안 보였나 | `inject_v1.py`는 `decide(rec, "", tbl)`만 썼다. LLM 출력이 없으면 `merge_facts`가 정규식 사실 전체를 돌려준다 |
| 수정 | `FACT_KEYS`에 `"특정기관_근거"` 추가. 이 키를 읽는 판정은 v1뿐이고, v1만 `or` 모드에서 가져온다 |

int8 본 호출은 dev의 '…만 참여 가능' 형 v1 4건(DEV-01·035·049·058)을 모두 잡으므로 이 수정의 몫은 평가셋 편집 문장을 LLM이 놓친 경우뿐이다. 자연 공고 20,000에서 이 정규식은 0회 켜진다 → 손해 경로가 사실상 없다.

- **최종 순위가 팀 최고 점수라면**(공식 페이지 문구는 "Private Score = 대회 종료 시점의 Public Score"뿐이고 최종 제출 선택 방식은 명시되지 않았다 — 제출 탭에서 확인 필요) 떨어지는 제출은 최고점을 깎지 않는다. 그러면 분산이 큰 소액수의 판을 **먼저** 내는 편이 낫다.
  - 두 판(09-26 판 A, 09-27 판 B) 결과를 모두 보는 데 이틀이 드는 것은 순서와 무관하다.
  - B를 먼저 내서 크게 오르면 A를 따로 낼 필요가 없어 하루가 남는다. 떨어지면 다음 날 A(또는 B에서 v10 소액수의만 뺀 판)를 내 가르면 된다.
- 최종 순위가 마지막 제출이나 선택 제출이라면 기존 계획(A → B)도 합리적이다. 마지막 날에는 최고점 판을 다시 내거나 선택한다.
