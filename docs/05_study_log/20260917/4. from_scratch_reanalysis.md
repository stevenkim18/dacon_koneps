# 처음부터 다시 분석: 라벨은 "법 조문의 기계적 적용"이다

## 1. 계기

리더보드 상위권은 0.7대인데 우리 최고점은 0.215(공식 베이스라인), 로컬 후보도 0.25 수준이다. 프롬프트·컨텍스트를 조금씩 바꾸는 방식으로는 차이를 설명할 수 없어서, 기존 가정을 버리고 dev 200건 정답·메타·법령패키지를 처음부터 다시 대조했다.

## 2. 핵심 결론

**24개 항목 대부분은 "LLM의 법률 판단"이 아니라 `(메타 금액·계약유형) + (본문에서 뽑은 사실 몇 개) → 법령 조건식`으로 결정된다.**
현재 파이프라인은 LLM 한 번 호출로 24개를 동시에 "판단"시키는데, 4B-활성 모델에게 법령 금액 구간·예외 조항 계산까지 맡기는 구조라 점수가 낮다. 상위권과의 차이는 여기서 나온다고 본다.

→ 구조를 **LLM = 사실 추출기(JSON), Python = 법령 판정기**로 뒤집어야 한다.

### v23은 날짜 계산 문제다

`지방자치단체 입찰시 낙찰자 결정기준` 제7장 제3절 2-다: 제안요청서 설명은 **제안서 제출마감일 전일부터 기산해 추정가격 1억 미만 10일 / 10억 미만 20일 / 10억 이상 40일 전**에 해야 한다. dev 양성 5건 모두 이 간격이 부족하다(예: DEV-27 설명회 2/3 → 마감 2/6, 필요 10일).
→ LLM은 "설명회 일시"와 "제안서 마감 일시"만 뽑고, 판정은 코드가 한다.

### 지방계약 금액 기준이 다르다

`지방계약법 시행규칙` 제24조 제2호 나목: 지역제한 가능 금액은 법 제5조 미적용 지자체 **5억**. dev에서 v5 양성의 지방계약 건은 5.4~6억, 지방계약 3~4억대 지역제한은 v5가 아니라 v6·v7로 라벨돼 있어 정확히 일치한다. 기존 meta_rules 후보는 전부 2.3억으로 게이트해 이 구분을 놓치고 있다.

## 5. 주의할 점

1. 규칙을 dev로 만들고 dev로 쟀으므로 낙관적이다. 규칙이 켜지는 비율을 무라벨 20,000건에서 함께 봐야 한다(v22 1.2%, v7 4.0% — 극단적이지는 않음).
2. 평가셋 분포는 무라벨과 비슷할 가능성이 높다. 무라벨은 **수의계약·소액수의견적이 45%**인데 dev는 17.5%다. 소액수의 건에서 규칙이 과발화하지 않는지 확인해야 한다.
3. v14–v18은 단순 "문구 있음/없음"으로는 안 갈린다(DEV-039는 "제한경쟁(소기업·소상공인)"이 있는데도 v18 양성). 참가자격 절에 실제 제한이 있는지를 LLM이 판별해야 한다.
4. 규칙상 공고마다 고정 LLM을 1회 이상 정상 호출해야 한다. LLM을 추출기로 쓰면 자연스럽게 충족된다.
5. 2시간 제한: 베이스라인 1회 호출이 38분이었으므로 공고당 추출 호출 2–3회(그룹별)까지는 여유가 있다.

## 7. 추가 분석: 규칙 정밀화 (같은 날 후속)

`scripts/rule_probe.py`를 갱신했다. 정규식만으로 측정한 dev F1과 무라벨 20,000건 발화율이다.

| 항목 | 새로 확인한 규칙 | dev F1 | 무라벨 발화 |
|---|---|---:|---:|
| v2 | 참가자격 실적 + 추정가격 < 2.3억(국가·지방 공통) + 지방 소액수의 제외 | 0.923 | 0.95% |
| v3 | 요구 실적금액 ≥ 배정예산 | 1.000 | 0.30% |
| v4 | 실적 발주처를 국가·공공기관 등으로 한정(민간 포함 시 제외). 금액 무관 | 0.909 | 0.40% |
| v6 | 제한 문장에 `[지역:…단위=기초]` 또는 `[수요기관(기초자치단체)]` | 0.714 | 2.71% |
| v7 | 제한 지역에 광역 2개 이상 | 0.875 | 2.69% |
| v8 | **지방계약만** 실적+지역 동시 제한(지방 시행규칙 제25조 제7항) | 0.800 | 0.14% |
| v20 | SW사업 + 추정가격 ≥ 1억 + 대기업·상호출자제한 문구 없음 | 0.909 | 0.92% |
| v21 | 최소지분율 < **지방 5% / 국가 10%** | 1.000 | 0.07% |
| v22 | 협상 + 설명회 미참석 시 참가 불가 | 1.000 | 1.17% |

- **평가표·제출서류의 "실적 기재"는 제한이 아니다.** 참가자격 문장만 봐야 v2 오탐 21건이 0건이 된다.
- **항목표 비고 "지방 + 소액수의 가능"** = 지방 소액수의견적은 v2·v6·v7·v8 위반 대상이 아니다. dev 지방 소액수의 29건 중 지역·실적 위반 라벨 0건.
- **익명화 토큰이 판정 재료다.** "강원도 [지역:r1|단위=기초]"는 원문에 시·군 이름이 있었다는 뜻이라 v6(시·군·구 제한)이다.
- **v14–v18**: 법령(판로지원법 시행령 제2조의2)대로 1억 미만→소기업·소상공인, 1억~2.3억→중소기업, 2.3억 이상→제한 금지. 오탐을 열어 보면 규칙이 아니라 "중·소기업·소상공인"(=중소기업 수준)을 정규식이 소기업으로 오독한 것이다. 경쟁제품(중기부고시 CSV)·수의계약·제2조의3 예외 사유는 제외해야 한다. **참가자격의 제한 수준 한 개를 LLM이 enum으로 뽑는 것이 핵심.**
- **v24**: 공고 제목·머리말의 계약방법·금액구간·지역·업종을 메타와 대조한다. 예: DEV-057 제목 "(일반경쟁·1억원미만)"인데 메타 추정가격 2.7억, 본문은 제한경쟁·경기도 제한인데 메타 지역제한 N.
- 무라벨 발화율이 높은 v18(10.2%, 그중 850건이 지방 소액수의)·v6·v7(2.7%, 주소·납품장소 오인)은 LLM으로 "참가자격 제한 문장인지" 확인이 필요하다.

### 추가로 확인한 법령 기준

- **경쟁제품(v10~v13)**: 세부품명 CSV의 특이사항에 금액 한도가 있다("추정가격 3억원 미만에 한함" 등). DEV-054 축제기획 3.27억은 한도 초과라 일반제품 → 직생 요구가 v12. v12 양성은 "실제 계약 목적물과 무관한 품목의 직생 요구"(연구과제에 행사기획 직생 등)다. 코드가 본문에 없는 행사대행 용역이 많아 LLM이 후보 세부품명 중 목적물을 고르게 했다.
- **수의계약**은 dev에서 경쟁제품·판로지원 계열 위반 라벨이 0건(판로지원법 제7조는 경쟁입찰 규정). 추정가격 1원·5원 단가계약은 금액 판정 제외.
- **v23 날짜**: 표가 줄 단위로 풀려 마감 날짜가 다음 줄에 오므로 키워드 뒤 3줄까지 본다.

|---|---:|

### 약한 항목 분석에서 알게 된 것
