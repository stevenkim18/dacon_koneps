# 평가셋 분포 추정과 기업규모 판정 정리

## 1. 평가셋은 무라벨보다 위반 공고가 훨씬 많이 섞여 있다

무라벨 250건 표본 검토에서 audit_v9의 정밀도는 0.596으로, dev만 볼 때는 보이지 않던 오탐이 많았다. 그렇다면 평가셋도 무라벨처럼 정상 공고 위주인지 확인했다.

방법: rule_extract(Public 0.6248)의 항목별 판정을 두 종류 공고에 나눠 셌다.
- dev형 공고: dev 200건의 정탐·오탐·놓침
- 무라벨형 공고: 표본 250건의 정탐·오탐, 놓침은 dev 재현율로 추정

평가셋 1,853건 중 dev형 공고 비율을 바꿔 가며 macro F1을 계산했다.

| dev형 공고 비율 | 예상 macro F1 |
|---:|---:|
| 0% (무라벨 분포) | 0.32 |
| 10% | 0.52 |
| 30% | 0.62 |
| 50% | 0.66 |
| 100% | 0.72 |

- 실제 Public 0.625는 무라벨 분포만으로는 나올 수 없다. dev형 공고가 적어도 30~50%는 섞여 있다고 봐야 한다(dev 부분은 dev 전체로 고른 낙관치라 실제 비율은 더 높을 수 있다).
- 표본이 250건이고 검토된 정탐이 34건뿐이라 거친 추정이다.
- **판단 기준:** dev 교차 검증을 주 지표로 쓰고, 무라벨 정밀도는 "크게 나빠지지 않았는지" 확인하는 보조 지표로 쓴다.

## 2. 기업규모 판정의 남은 오류

audit_v9의 dev 오류를 열어 보니 v11·v13·v15·v17 오류 상당수가 품목이 아니라 **기업규모 수준·우선조달 예외 해석** 문제였다.

- **비영리법인 문구는 예외가 아니다.** "시행령 제2조의3 제1항 제2호에 따라 비영리법인은 확인서 없이 참가 가능"은 많은 공고에 들어가는 정형 문구다. 제2조의3 ①2호(학술·연구·교육 위탁용역의 비영리법인 참가)는 소기업·중소기업 제한을 그대로 둔 채 비영리법인을 더 받는 것이다. dev도 이 문구가 있는 공고를 v15·v17 위반으로 라벨했다(DEV-055·073·079·080). 진짜 예외는 "제2조의3 제①항4호 … 중소기업에 대한 참가자격은 제한하지 않습니다"처럼 제한 자체를 풀어 준다.
- **확인서 종류가 수준을 정한다.** "중소기업 또는 소상공인으로서 … 소기업·소상공인 확인서를 소지한 업체"는 dev에서 소기업 수준이다(DEV-076·077 v13). 반대로 "소기업 또는 소상공인 … 〈중소기업·소상공인 확인서〉"는 확인서 이름 속 '중소기업' 때문에 오독하기 쉽다.
- **LLM이 메타를 근거로 답한다.** 기업규모 근거로 본문이 아닌 "조항호내용: [판로지원법 시행령] 소기업,소상공인제한"을 내는 경우가 있다. 라벨은 본문 기준이다.

수정 결과는 [`submissions/20260918_sme_level`](../../../submissions/20260918_sme_level/README.md)에 정리했다: dev 0.7711 → 0.8174, 교차 검증 0.7438 → 0.7849, 무라벨 정밀도 0.596 → 0.607(정탐 34 → 37).

## 3. 다음 약점: 품목 판별

무라벨 v10 판정 12건 중 오탐 8건이고, 그중 6건은 멘토링·연수·숲해설 같은 **소프트웨어와 무관한 '운영 위탁'을 운영위탁서비스(IT, 8111181101)로 고른** 경우다. 이 품목의 고시 CSV 특이사항은 "소프트웨어 진흥법 제48조 적용"이다. 품목 전용 호출도 같은 공고를 기타행사기획(8014199001)으로 연결해 거부권이 작동하지 않는다.

- SW 사업이 아니면 이 품목을 경쟁제품에서 빼는 단순 규칙은 무라벨 오탐 23 → 14였지만 정탐도 34 → 30으로 줄었다(다른 경쟁제품이 맞는 축제 운영 등까지 빠짐). 빼기보다 품목을 다시 고르는 방식이 필요하다.
- 물품은 경쟁제품 616개 중 181개에 조건이 붙어 있다(컴퓨터서버 "x86 … 3.2GHz 이하", 간장 "혼합간장에 한함", 드론 중량·고도 조건). dev v10 오탐 DEV-09·170은 조건 미확인이다. DEV-23·088은 본문에 "시행령 제7조제1항제4호 … 일반물품으로 입찰공고", "직접생산확인증명서를 별도로 요구하지 않습니다"라는 제외 문구가 있었다.
