# 모델에 전달할 문서 확인

## 실행

```bash
python3 scripts/inspect_context.py
```

[스크립트](../../../scripts/inspect_context.py)는 공식 베이스라인의 함수를 직접 호출해 `PPS-DEV-01`의 입력을 구성한다. 모델 설치는 필요 없다.

## 확인한 결과

| 문서 | 원본 본문 | 입력에 포함된 본문 |
|---|---:|---:|
| 공고문 | 6,749자 | 3,991자 |
| 과업지시서 | 14,596자 | 0자 |

- 기본 문서 예산 4,000자에는 문서 제목 표시도 포함된다.
- 공고문 뒷부분은 잘리고, 과업지시서는 통째로 빠졌다.
- **v1의 정답 근거는 이 입력에도 포함되어 있다.** 따라서 이 사례의 v1 근거가 잘려서 점수가 낮았다고 해석할 수 없다.
- 실제 서버의 이 공고 예측값은 확인하지 않았다. 이번 실습은 입력 구성 확인이다.
- 실제 실행에서는 토크나이저로 길이를 계산한 뒤 입력이 더 줄어들 수 있다.

## 읽을 내용

1. [비교 보고서](../../04_learning/examples/PPS-DEV-01-context/README.md)를 읽는다.

3. [전체 문서](../../04_learning/examples/PPS-DEV-01-context/full_documents.txt)와 비교한다.
