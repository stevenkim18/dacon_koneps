## 기준 버전과 변경 사항

기존 후보들(베이스라인 계열)과 구조가 다르다. LLM에게 24개 항목을 "판단"시키지 않는다.

| 단계 | 역할 |
|---|---|
| 문맥 구성 | 공고문 머리말 1,200자 + 문서 전체에서 키워드 그룹(참가자격·실적·지역·기업규모·직접생산·설명회·일정·공동수급·SW·확약서·모델·기관한정·계약개요)에 걸린 줄만 발췌 + 세부품명 후보(원문 번호 + 공고명과 비슷한 경쟁제품) |
| LLM 1회 호출 | 29개 사실 필드를 JSON Schema로 추출(판정 금지, 근거는 원문 그대로) |
| 정규식 | 같은 사실을 원문에서 다시 추출 |
| 판정기 | 메타 금액·계약유형 + 사실 + 법령 기준으로 v1~v24 판정 |

### 판정기가 쓰는 법령 기준

- 고시금액 2.3억(국가·지방 공통 실적·판로지원 구간), **지방 지역제한 기준 5억**(지방계약법 시행규칙 제24조)
- 지방 소액수의견적은 실적·지역 제한 위반 대상 제외(항목표 비고 "지방 + 소액수의 가능")
- 수의계약은 경쟁제품·판로지원 위반 대상 제외, 추정가격 100만 원 미만(단가계약)은 금액 구간 판정 생략
- 판로지원법 시행령 제2조의2: 1억 미만 소기업·소상공인 / 1억~2.3억 중소기업 / 2.3억 이상 제한 금지
- 경쟁제품 = 세부품명 CSV 등재 + 특이사항 금액 한도("추정가격 3억원 미만에 한함" 등) 충족
- 지방계약법 시행규칙 제25조 제7항: 지방계약 실적+지역 중복 제한 금지(v8)
- 공동수급 최소지분율 지방 5% / 국가 10%(v21)
- 지방 협상계약 설명회는 제안서 마감 전일부터 10/20/40일 전(낙찰자 결정기준 제7장 제3절, v23)
- v9는 '동등 이상' 허용 시 제외, v19는 제조사 공급·기술지원 확약서를 입찰·마감 시점에 요구한 경우만
