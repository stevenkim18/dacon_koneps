### 채택 규칙 (2026-09-21 교체, 09-22 보완)

## 폴더 규칙

새 제출은 `YYYYMMDD_버전명/` 폴더를 만들고 다음을 보존한다.

```text
submissions/
├── README.md
└── YYYYMMDD_version/
    ├── README.md
    ├── submit.zip
    ├── dev_validation.log
    ├── mock_validation.log
    ├── script.py              # 수정본이면 압축 밖에도 보존
    └── requirements.txt       # 수정본이면 압축 밖에도 보존
```

공식 원본처럼 별도 수정이 없는 제출은 ZIP만 보존하고, 출처 파일과 바이트 일치 여부를 README에 기록할 수 있다.

**제출 전 점검(09-22 기준 명령):** dev 재채점(`scripts/mlx_eval_extract.py … --score-only --cv`) · 무라벨 20,000 재생(`scripts/replay_unlabeled.py`, 예외 0) ·
무라벨 750 차이(`scripts/eval_unlabeled750.py`) · 근거 문구(`scripts/evidence_audit.py`) · mock(`PPS_DATA_DIR=open/data PPS_OUTPUT_DIR=… python script.py --mock`) · ZIP 안팎 해시.
