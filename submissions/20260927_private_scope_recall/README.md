## 점수 추정 (제출 전 고정, 09-26 결과 S26 대비)

이 후보는 **"평가셋이 소액수의 공고에도 v10·v17을 적용해 라벨했는가"** 하나에 크게 걸려 있다.
- **라벨했다면**(항목표가 v10 근거로 든 판로지원법 제9조 ①1호가 소액수의를 명시, v17 대표 예시 DEV-21이 소액수의): 평가셋 자연 공고 부분에서 v10 약 +45 · v17 약 +10의 누락을 새로 잡는다 → **+0.010~0.020**.
- **라벨하지 않았다면**(dev 5월 묶음 DEV-090형): v10 약 +50 · v17 약 +10이 오탐 → **−0.008~−0.015**.
- 편집 재현율 몫(v3·v23)과 파서 수정은 평가셋에 그런 문장이 있을 때만 +0.000~0.004.
- 09-25의 v8 국가계약이 같은 구조(항목표 조문의 범위를 코드가 좁혀 둔 것)였고 크게 올랐다. 기대값은 양이라고 보지만 폭이 크다.

| **≥ +0.008** | 소액수의 v10·v17이 평가셋에서 정탐 | 유지. v13·v16·v18 등 다른 수의계약 게이트도 조문으로 재검토 |
| 0 ~ +0.008 | 둘 중 하나만 맞거나 효과가 작음 | 유지 |
| **< 0** | 소액수의가 평가셋에서 라벨 0 | `make_v10q.py`의 1번(v10 소액수의)과 `make_sent2.py`의 E 블록(v17 소액수의)만 되돌린 판을 09-28에 낸다. v3·v23·파서 수정은 남긴다 |
