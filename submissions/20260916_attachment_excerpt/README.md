## 목적

09-16 `balanced_context`(미채택, -33.96%)는 문서 예산 확대·법령 조문명 추가·보수적 0 지시·발췌 방식을 한 번에 바꿔 원인을 분리할 수 없었다. 이번에는 공식 베이스라인에 **검증된 변경만** 쌓는다 — 각각 독립적으로 근거와 dev 정답 대조 결과가 있다.

## 변경 사항

- 시스템 프롬프트, 공고문 4,000자 예산 로직(`build_context`), 모델 호출, JSON 파싱, CSV 저장, 자가검증 — **전부 공식 베이스라인과 동일**.
1. **`attachment_excerpts()`**: 첨부문서(규격서·과업지시서·제안요청서·예외공표서)에서 앵커 키워드·제품 코드 패턴 주변만 최대 ~1,000자 짧게 발췌해 덧붙인다(공고문 4,000자 + 첨부 ~1,000자 ≈ 5,000자).
2. **v22·v23 메타 적용 게이트**(`postprocess`): 항목표.json 항목명은 "계약방법 협상"이라 적혀 있지만 dev 200건엔 `계약방법='협상'`이 아예 없다. 실제 조건은 `낙찰방법=='협상에의한계약'`(v23은 추가로 `적용계약법=='지방계약법'`)이며, dev 200건 양성 전수 검증 결과 예외 0건 — 벗어나면 0으로 강제해도 재현율 손실이 없다.
3. **v13 세부품명번호 대조**(`load_sme_competitive_codes`): "소기업·소상공인 확인서 소지자에 한함" 문구만으로는 v13이 성립하지 않는다 — 법령패키지의 중기간 경쟁제품 목록(615개 세부품명번호)에 있을 때만 위반이다. dev 오탐 중 세부품명번호가 있던 건은 전부 목록 밖 품목이었고, 진짜 양성은 전부 세부품명번호가 메타에 없어 이 규칙에 걸리지 않는다.
